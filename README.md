# CS Circles (Nederlands) in PreTeXt

Omzetting van de Nederlandse editie van [Computer Science Circles](https://cscircles.cemc.uwaterloo.ca/nl/)
naar [PreTeXt](https://pretextbook.org), voor gebruik op Runestone Academy.

## Bouwen

```
pip install -r requirements.txt
pretext build web        # statische HTML
pretext build runestone  # voor een Runestone-server
pretext view web
```
